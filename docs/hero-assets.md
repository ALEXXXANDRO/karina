# Ассеты первого экрана PORTFOLIO

## Источник и область работ

- [Страница макета](https://www.figma.com/design/e2Zs6Sgj3jMQ282n7ujxxi/?node-id=141-11984): `Page 8`, узел `141:11984`.
- [Обложка](https://www.figma.com/design/e2Zs6Sgj3jMQ282n7ujxxi/?node-id=141-12805): фрейм `861036610`, узел `141:12805`, **1920×1080 px**.
- Во фрейме одна группа текста и **13 самостоятельных декоративных объектов**. Часть объектов состоит из изображения и векторной маски; экспортировались целые группы, а не исходные изображения без масок.
- Каталог файлов: `public/assets/hero/`; будущие публичные пути: `/assets/hero/<имя-файла>`.
- Документ описывает экспорт декора; обложка реализована отдельно в `src/sections/Hero/`.

## Статус экспорта

**Экспорт завершён частично: 6 прозрачных PNG, 5 промежуточных PNG с фоном, 2 файла отсутствуют.** Все 13 объектов существуют как отдельные слои или группы; препятствие связано с экспортом и лимитом MCP, а не с отсутствием самостоятельных элементов.

Первый способ, Figma MCP `download_assets` с `defaultFormat: png`, вернул 11 PNG с тёмным фоном: альфа каждого пикселя **255**. Наличие канала RGBA само по себе не означает прозрачность.

Затем через Figma MCP `use_figma` выполнен изолированный `node.exportAsync({...settings, contentsOnly: true})`. Использовались PNG-настройки исходного слоя: для групп задан масштаб 2×, а у трёх голубых объектов настроек экспорта нет — применён стандартный PNG 1×. Шесть файлов удалось полностью получить и заменить прозрачными экспортами. Данные передавались частями из-за ограничения размера ответа MCP; незавершённые файлы не сохранялись.

Повторный экспорт остановлен ошибкой лимита вызовов Starter, подтверждённой `whoami`. Для пяти объектов сохранены прежние промежуточные PNG с фоном, для двух (`141:12823`, `141:12835`) файлов нет. Эти семь объектов пока не готовы к использованию. Заглушки, произвольные замены и ручное удаление фона не применялись. Пропорции, повороты и содержимое полученных экспортов не изменялись; Figma-файл не редактировался.

Повторная проверка **20 октября 2026 года**: изолированный экспорт `141:12813` снова отклонён Figma MCP из-за лимита Starter; `whoami` подтвердил текущий тариф. Новые PNG не получены. Продолжение возможно после восстановления доступа к экспорту либо получения вручную экспортированных прозрачных PNG этих семи слоёв.

## Типографика и эффекты обложки

- Фон фрейма: `#1C1C1C`; текст: `#FFFFFF`.
- Текстовая группа `141:12806`: 1430×281 px, x=245, y=400 при размере фрейма 1920×1080.
- PORTFOLIO: Inter Black, 900, 237,364 px, uppercase, line-height 1; блок 1430×224 px.
- Совпадающие слои заголовка: `141:12807` с blur 5 px и резкий `141:12808`.
- Подпись `141:12809`: «karina shishkalova • graphic designer • illustrator», uppercase, Inter Semi Bold, 600, 27,36 px; блок 1430×35 px, x=245, y=646, blur 1,5 px.
- Масштабы, повороты и маски декора заданы исходными слоями. У полученных PNG поворот уже включён в изображение; повторно вращать их без сверки с макетом нельзя.
- Размытие текста — статический эффект. Анимации не добавлялись. Текст и фон обложки в PNG декора не включаются намеренно; обнаруженный тёмный фон является ограничением полученного экспорта.

## Проверка и оставшаяся работа

Все 11 файлов непустые; проверены PNG-сигнатура, CRC блоков, распаковка пикселей и диапазон альфа-канала. У шести готовых файлов диапазон альфа-канала **0–255**, у пяти промежуточных — **255–255**. Каждый окончательно сохранённый файл открыт через просмотрщик изображений и визуально сверён с соответствующим объектом обложки. Пропорции полученного экспорта сохранены. Временные URL Figma не записаны в исходники или этот документ.

Чтобы завершить задачу после восстановления лимита MCP, требуется изолированный экспорт семи объектов: `141:12813`, `141:12816`, `141:12823`, `141:12826`, `141:12835`, `141:12836`, `141:12840`. Использовать PNG-настройки каждого слоя и `contentsOnly: true`, затем проверить прозрачность и маски. Для пяти из них заменить промежуточные файлы, для двух создать отсутствующие.

На этапе экспорта `npm run build` прошёл; код компонентов и стилей тогда не изменялся. Реализация обложки описана ниже.

## Реализация Hero

- `src/sections/Hero/Hero.tsx` содержит семантический заголовок `h1` и подпись,
  а `Hero.css` — стили, статическое размытие и адаптивное расположение.
- `heroObjects.ts` хранит конфигурацию всех 13 объектов, node ID, пути,
  координаты и статус. Отрисовываются только шесть записей со статусом `ready`.
  Отключённые PNG не попадают в DOM и не запрашиваются браузером.
- После корректного экспорта оставшихся объектов нужно проверить их
  прозрачность и заменить статус на `ready`. Координаты уже подготовлены.
- На десктопе композиция масштабируется пропорционально от 1920×1080,
  ограничена шириной 1920 px и центрируется в первом экране.
- Мобильного референса нет. Для портретных экранов до 1024 px и всех экранов
  до 600 px предложена отдельная композиция: заголовок по центру, перенос
  подписи и увеличенные относительно экрана объекты вокруг текста.
  Компактные координаты в конфигурации являются адаптивным допущением.
- Эффект свечения — второй HTML-слой заголовка с `aria-hidden`, поэтому
  скринридер озвучивает PORTFOLIO один раз. У декора пустой `alt`.
- Новые изображения, анимации, библиотеки и scroll snap не добавлены.
  Figma MCP при реализации не вызывался. Исходные PNG не изменялись.

Проверка реализации в локальном Chrome: 1920×1080, 1440×900, 1024×1366,
768×1024, 390×844, 360×740, 320×568 и 844×390. Все шесть PNG загружаются
и помещаются в пределах экрана; горизонтального переполнения, наложений
на текст, ошибок JavaScript и запросов отключённых файлов нет. На 1920×1080
проверены координаты заголовка (245, 400), подписи (245, 646), размер шрифта
237,364 px и blur 5 px. Для альбомной ориентации 601–1024 px композиция
также ограничивается высотой viewport.
