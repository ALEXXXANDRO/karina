# Глобальный фон из Figma

Источник: https://www.figma.com/design/U1ClZsnNV5IEjsUKZfYr8M/?node-id=185-75
Узел 185:75, Group 2087327002. Макет прочитан через Figma MCP; оригинальный
прозрачный SVG сохранён в src/effects/GlobalAtmosphere/figma-marks.svg.
Естественный размер экспорта — 688×664.363 px, включая поля эффекта размытия.

## Замена объектов

Прежний генератор штрихов, плюсов, крестиков и регистрационных знаков удалён
вместе с его типами, случайными потоками и настройками вращения. Вместо него
используется точная экспортированная композиция: серые размытые наклонные черты,
решётки и многолучевые типографские астериски. Некоторые формы похожи по названию
на прежние элементы, но теперь они целиком происходят из SVG заказчика.
Геометрия, взаимное расположение, цвета и исходное размытие внутри SVG не меняются.
Звёздная пыль, цветные свечения и космические эффекты не добавляются.

Композиция повторяется по горизонтали и вертикали на одном фиксированном Canvas
за контентом. Это адаптация предоставленной группы к фону всей страницы, а не
копия положения каждого объекта в макетах отдельных секций. Вращение всей группы
не применяется: оно наклоняло бы повторяемую композицию целиком. Для независимых
поворотов понадобятся отдельные экспорты объектов; текущий SVG не разрезается.

## Конфигурация

portfolioEffects.globalAtmosphere в src/effects/config.ts:

- enabled — независимое отключение компонента и обработчиков.
- tileScale: 1 — масштаб всей исходной композиции. Количество объектов внутри
  экспорта фиксировано; меньший масштаб делает повторение плотнее и объекты меньше,
  больший — реже и крупнее. Отдельных strokeCount/markerCount больше нет.
- mobileTileScale: 1.25 — более редкое повторение на мобильных; адаптация без
  отдельного мобильного референса. Пропорции SVG сохраняются.
- opacity: 1 — дополнительная прозрачность поверх исходных цветов/прозрачности SVG.
- scrollFactor: 0.54 — общее смещение −window.scrollY×0.54 без clamp.
- cursorOffset: 4, cursorResponseMs: 180 — слабая реакция на мышь и плавность возврата.
- mobileBreakpoint: 768 — отключение курсорной реакции и переход к мобильному масштабу.
- maxDpr: 2 — ограничение разрешения Canvas и растрового кеша.

## Отрисовка и доступность

SVG один раз растеризуется в отсоединённый Canvas-кеш при загрузке, resize или
смене DPR/режима ввода. На каждом scroll-кадре копируются только готовые тайлы:
SVG-фильтр размытия не пересчитывается для каждого повторения. В DOM остаётся
один viewport-Canvas фона. Vite обрабатывает локальный импорт SVG, включая /karina/;
временных URL Figma в исходном коде нет.

Положительный modulo вычисляет начало повторения, соседние тайлы покрывают края
viewport без пустых полос. Позиции зависят только от scrollY и курсора; переходы
между секциями ничего не сбрасывают. Пассивные события запускают RAF по требованию,
в покое перерисовка останавливается. Обработчики, ResizeObserver, RAF и onload
очищаются при размонтировании. При reduced motion фон статичен.

Основа #1C1C1C и статичная зернистость сохранены. Фон имеет aria-hidden и
pointer-events: none. CursorTrail остаётся отдельным неизменённым Canvas над
контентом. Hero, галереи, заголовки, параллакс иллюстраций и Scroll Snap не менялись.

## Проверка

node --test tests/*.test.mjs: 13 тестов, включая размеры локального SVG,
равномерную скорость, покрытие viewport, циклический перенос и обратимость.
npm run build: строгая проверка TypeScript, Vite и prerender прошли.

В Chrome production preview просмотрены Hero и описания трёх проектов, пройдены
семь snap-позиций. Во время нативного snap с 0 до 1080 px измерено смещение
583.2 px; возврат восстановил исходный Canvas. Проверены остановка RAF, reduced
motion, глобальный CursorTrail и ширины 1920/1440/1024/768/390 px. Переполнений
и ошибок консоли приложения не обнаружено. Скриншоты проверки находятся вне
репозитория в /private/tmp/karina-atmosphere-check/figma-*.png.
