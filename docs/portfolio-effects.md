# Независимые эффекты портфолио

## Включение и настройки

Общая точка настройки — `src/effects/config.ts`. У `traveler`, `titles`
и `gallery` есть независимый флаг `enabled`: значение `false` отключает
только соответствующий эффект. Новых зависимостей и изменений данных
проектов нет. Исходные стили Grid и типографика сохранены.

`useMotionEnabled.ts` подписывается на media query и отключает эффекты
при `prefers-reduced-motion: reduce`, включая смену настройки на открытой
странице. Подписки удаляются при размонтировании.

## Боб-путешественник

Модуль: `src/effects/TravelerBean/`. Подключён отдельно от Hero и вне
потока документа. Использует существующий `assets/hero/bob16mini.png`;
путь строится через `import.meta.env.BASE_URL`, включая `/karina/`.

IntersectionObserver наблюдает три вводные секции проектов и Hero.
Боб показывается рядом с переходом к проекту после появления хотя бы 10%
его секции; пока Hero виден, появление откладывается. При возвращении к
Hero боб скрывается. На каждый проект приходится не более одного появления
за время жизни страницы, а между появлениями выдерживается cooldown.
Если пользователь быстро пролистывает проекты, промежуточные появления
могут быть пропущены: таймер повторных попыток не запускается.

Настройки `traveler`:

- `size`: ширина 120 px.
- `visibleFraction`: видимая доля ширины 0.5.
- `stayMs`: 3000 ms до автоматического ухода.
- `cooldownMs`: минимум 12000 ms между появлениями.
- `cursorRadius`: радиус испуга 110 px.
- `minWidth`: эффект доступен от 1101 px; на планшетах и телефонах отключён.
- `asset`: локальный PNG.

В TravelerBean.css задаются обычный переход 550 ms и испуг 180 ms.
На каждое появление создаётся только один timeout. Постоянного scroll listener
и interval нет. Перед появлением подбирается свободная вертикальная позиция
у правого края без пересечения с HTML-текстом и элементами управления.
Дополнительный IntersectionObserver следит за областью выглядывания:
если при прокрутке туда попадает текст или элемент управления, декор сразу
скрывается, включая фазу ухода. Оба observer отключаются в cleanup.
Декор имеет `aria-hidden` и `pointer-events: none`, не получает фокус,
не перехватывает клики и не расширяет страницу.

## Появление заголовков

Модуль: `src/effects/ProjectTitles/`. Hook подключён к существующему h2
в ProjectIntro; MASCOT S7 анимируется целиком, обе строки вместе.

IntersectionObserver запускает анимацию при видимости 25% заголовка и
затем отключается. Повторного запуска при прокрутке или смене reduced motion
нет. Настройки `titles`: `durationMs` 800 ms, `offset` 36 px,
`stretch` 1.08. Ключевые кадры приземления — в ProjectTitles.css.

Анимируется только transform. Место заголовка в Grid не меняется;
предварительного скрытия через opacity/visibility нет. Без кода эффекта
заголовок отображается в обычном состоянии. Это не меняет общую модель
React SPA: полноценный серверный HTML без JavaScript не добавлялся.

## Живые галереи

Модуль: `src/effects/LiveGallery/`. Один hook на галерею обрабатывает
движение мыши через делегирование. Смещения и наклоны записываются в
CSS-переменные через requestAnimationFrame, без React setState на кадрах.
После достижения цели цикл останавливается.

Настройки `gallery`: `lift` 6 px, `maxTilt` 4° по каждой оси,
`perspective` 1200 px, `followMs` 90 ms, `returnMs` 180 ms.
Большее время интерполяции делает реакцию мягче и медленнее.

Grid-ячейки и их размеры не изменены. Внутри каждой карточки добавлена
поверхность с прежним изображением и скруглением. Наклон ограничен
существующей обрезкой карточки; подъём дополнительно ограничивается реальным
зазором до карточки сверху, оставляя минимум 1 px. Это сохраняет узкие
зазоры вложенных сеток RAT DOT и исключает перекрытие соседей.

Эффект работает только при `(hover: hover)` и `(pointer: fine)` и возвращается
в исходное состояние при уходе указателя, прокрутке, resize и потере фокуса.
Карточки остаются обычными div: нет новых кликов, кнопок и tab stops.
Cleanup отменяет RAF, удаляет listeners и внесённые CSS-переменные.

## Проверки

`npm run build` успешно проверил TypeScript и собрал production-версию.
Через Vite preview на `/karina/` выполнены проверки Chrome при 1920×1080,
1440×900, 768×1024, 390×844 и 360×740; два последних размера — с эмуляцией
сенсорного устройства. Секции и все 21 Grid-слот сравнены с измерениями
до добавления эффектов: координаты и размеры в покое совпадают.

Проверены все три появления путешественника, автоматический уход, испуг,
cooldown, запрет повторного появления у того же проекта, отсутствие на Hero,
прозрачность для кликов и немедленное скрытие при прокрутке текста под декор.
У всех заголовков зафиксирован ровно один запуск анимации, включая возврат
назад по странице. MASCOT S7 сохраняет две строки в одном блоке.

На устройствах с hover проверены наклон, безопасный подъём и возврат
каждой карточки всех трёх галерей. На сенсорных экранах наклон и путешественник
отсутствуют. При reduced motion все декоративные анимации отключены,
заголовки и изображения доступны. Горизонтального переполнения, пересечений
карточек и исключений JavaScript нет; отдельная проверка консоли ошибок не
обнаружила. Скриншоты десктопной и мобильной версии просмотрены.

Проверен запуск прежнего кувырка Hero. Файлы Hero, данные проектов, исходные
стили сеток, PNG, Vite base и workflow публикации не изменены; проверены
контрольные суммы. Git push не выполнялся.
