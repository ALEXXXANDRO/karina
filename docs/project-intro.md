# ProjectIntro: первый экран RAT DOT

## Источник и размеры

Использован ранее полученный контекст Figma для фрейма `3 rat dot`,
узел `141:12737`, файл `e2Zs6Sgj3jMQ282n7ujxxi`. При этой реализации
Figma MCP не вызывался. Контрольный размер — **1920×1080 px**.

|---|---:|---:|---|
| Заголовок RAT DOT. | 64 | 81 | Inter Semi Bold 600, 173,647 px, line-height 1 |

Фон — `#1C1C1C`, текст — белый. Нижние подписи:
`KARINA SHISHKALOVA • 2026` и `RAT DOT`.

## Компонент и данные

- `src/components/ProjectIntro/ProjectIntro.tsx` — общая семантическая секция
  с `h2`, характеристиками `dl`, описанием, иллюстрацией и подписями.
- `ProjectIntro.css` — двухколоночный Grid; внутри описания также Grid,
  а нижние подписи используют Flexbox. Абсолютное позиционирование отсутствует.
- `src/types/project.ts` — строгая модель `ProjectIntroData`: строки заголовка,
  ровно три характеристики, абзацы описания, состояние иллюстрации и подписи.
- `src/data/ratDot.ts` — только данные RAT DOT. Компонент позволяет позднее
  передать данные WOLFS или MASCOT S7 без копирования разметки. Другие проекты
  сейчас не добавлены.
- В `App.tsx` секция подключена непосредственно после Hero. ABOUT и галереи
  отсутствуют; файлы Hero не изменялись.

## Иллюстрация

Вручную экспортированный файл `public/assets/RatDot/rat-dot-cover.png`
подключён через `illustration.status: 'ready'` в `src/data/ratDot.ts`.
Фактический регистр каталога — `RatDot`; он сохранён в URL для совместимости
с файловыми системами, чувствительными к регистру.

Исходный PNG имеет размер **935×999 px**. Пропорции совпадают с контейнером,
поэтому существующий `object-fit: cover` не обрезает изображение.
Дополнительный `object-position` не задан: используется центрирование.
При контрольном размере секции 1920×1080 контейнер располагается в точке
(965, 21), имеет размер 935×999 px и радиус 30 px. На узких экранах
масштабируется пропорционально. PNG не изменён.

Изображение загружается локально с учётом базового пути Vite, его место
зарезервировано до загрузки. Временные URL Figma не используются.

## Контент и возможные расхождения

- В исходном RAT DOT повторено описание WOLFS. Сохранены оба абзаца из
  референса; в данных стоит `unconfirmed-reference-copy`. Перед публикацией
  нужен утверждённый текст RAT DOT, его замена не придумана автоматически.
- Характеристики взяты из референса: Branding / Packaging; Store / Jewellery;
  2026. Отдельного подтверждения актуальности этих данных пока нет.
- Главная иллюстрация подключена из пользовательского экспорта без изменения
  содержимого и пропорций. Повторная сверка с Figma MCP не выполнялась.
- Цвет линии приблизительно передан белым с непрозрачностью 50%; точный
  цвет исходного SVG в локальных материалах не зафиксирован.
- Метрики строк и переносы могут немного отличаться от Figma: используется
  локальный Inter и обычный HTML-текст, а не изображения текста.

## Адаптивное поведение

На десктопе размеры пропорциональны ширине композиции, максимальная ширина
1920 px. Более короткая композиция центрируется в высоте экрана.
До 1100 px включительно секция перестраивается в одну колонку: название,
характеристики, описание, иллюстрация, подписи. Описание получает размер
16 px и line-height 1,5; высота секции определяется содержимым.
Три характеристики сохраняются в отдельных колонках.

Мобильного и планшетного макета в ранее изученных материалах нет. Эти правила
являются предложенной адаптацией, а не измерениями Figma. Анимации,
scroll snap и новые зависимости не добавлены.

## Проверки

В локальном Chrome проверены 1920×1080, 1440×900, 1280×800, 1100×900,
1024×1366, 768×1024, 390×844, 360×740 и 320×568. Подтверждены контрольные
координаты, размеры иллюстрации и нижних подписей при 1920×1080.
Горизонтального переполнения, пересечения описания с подписями и ошибок
JavaScript нет. RAT DOT следует непосредственно за Hero; в DOM ровно один
`ProjectIntro`. После подключения экспорта вместо пустого контейнера
отображается локальное изображение.

Контрольные суммы всех файлов `src/sections/Hero/` не изменились.
`npm run build` включает `npm run typecheck`; проверка типов и сборка успешны.
