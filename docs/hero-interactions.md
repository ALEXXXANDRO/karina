# Hero: реакции бобов и Bean Party

Существующая система Hero расширена без второй системы анимаций и зависимостей.
Расположение, размеры и повороты из `heroObjects.ts`, PNG, тексты заголовка
и подписи, Scroll Snap и остальные секции сохранены.

## Слои и реакции

`hero__object` задаёт позицию → `hero__float` сохраняет базовое парение →
`hero__reaction` обрабатывает курсор → `hero__bean-button` анимирует одну
индивидуальную реакцию → `hero__party` двигает изображение на вечеринке.
Парение при действии приостановлено и затем продолжается с той же фазы.
Реакция на курсор на время действия возвращается к нулю существующей
интерполяцией. Кувырки и деформации используют центр изображения.

В `src/sections/Hero/heroMotion.ts`:

- `durationsMs`: Jelly Bounce 780, Crazy Flip 900, Wiggle 650, Double Hop 1000 ms.
- `squashY: 0.86`, `stretchY: 1.16`: соответствующий масштаб X обратный,
  чтобы сохранялась приблизительная площадь силуэта.
- `jellyHeight: 28`, `flipHeight: 40`, `hopHeight: 32` px; второй hop вдвое ниже.
- `wiggleAngle: 14` градусов.

CSS keyframes находятся в Hero.css. `chooseBeanReaction` исключает предыдущую
реакцию конкретного боба. Пока реакция выполняется, новые клики по нему
игнорируются; другие бобы работают независимо. Управление остаётся нативным
button: мышь, касание, Enter и Space. При окончании/cancel данные действия
очищаются обработчиком существующего HeroBean, без покадрового React state.

## Bean Party

Настройки `heroMotion.party`:

- `enabled`: независимо отключает пасхалку.
- `requiredBeans: 5`, `windowMs: 10000`: пять разных бобов в скользящем окне.
- `durationMs: 4000`: общий срок вечеринки.
- `jumpHeight: 30`, `staggerMs: 35`: высота и различия фаз.

Считаются принятые клики, когда боб свободен. Повторы обновляют только время
того же боба. Пятый уникальный клик запускает вечеринку вместо индивидуальной
реакции; уже начатые реакции завершаются. После запуска счётчик очищается.
У всех 12 активных бобов включается конечная CSS-анимация с небольшими
задержками и чередующимися направлениями вращения. Длительность каждого
слоя учитывает задержку, чтобы все закончили в пределах общего срока.

Надпись BEAN PARTY! декоративная, не перекрывает постоянные заголовок
и подпись и пропускает клики. Конфетти не добавлялись. Клики во время
вечеринки не учитываются; фокус кнопки сохраняется через aria-disabled.
После окончания возможна новая серия из пяти разных бобов.

## Доступность и cleanup

При reduced motion все декоративные движения и запуск действий отключены;
активная вечеринка немедленно отменяется. При скрытии вкладки очищаются
индивидуальные реакции, счётчик и конечный таймер, базовое парение приостановлено.
При возврате обычные взаимодействия снова доступны. Cleanup hook удаляет
подписки, RAF и таймер вечеринки. Счётчик очищается по событиям, без interval.
`overflow: clip` на существующем слое декора исключает горизонтальный скролл;
button сохраняет touch-action: auto и не блокирует вертикальные жесты.

## Проверка

`node --test tests/heroMotion.test.mjs` проверяет выбор четырёх реакций,
запрет повтора, пять разных бобов, повторы одного, скользящее окно и сброс.
Используются Node test/assert и установленный TypeScript, без нового runner.
`npm run build` включает строгую проверку TypeScript и статический HTML
для GitHub Pages с base `/karina/`.

В Chrome проверены все четыре CSS-реакции, запрет повторов, 25 быстрых кликов,
независимость бобов, запуск после пяти разных бобов, отсутствие запуска
от повторов одного, окончание и повторный запуск вечеринки. Подтверждены
работа прежнего парения/курсора, отмена при reduced motion (включая отмену
CSS-анимации до доставки media query change) и фактической смене вкладки.
На 1920×1080, 1440×900, 768×1024, 390×844 и 360×740 проверены неизменные
координаты/размеры обёрток, отсутствие горизонтального скролла и перекрытия
подписи декоративной надписью. Снимок мобильной версии просмотрен.
Проверены нативное касание, вертикальный touch-жест от кнопки боба и
Enter/Space. Исключений JavaScript и ошибок гидратации не обнаружено;
прежний запрос favicon.ico с 404 не относится к эффектам Hero.
